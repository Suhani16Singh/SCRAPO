# ♻️ ReLoop – E-Waste Management & Circularity Platform

**Give Electronics a Second Life.**

ReLoop is an e-waste management and circular economy platform designed to reduce electronic waste by connecting device donors, recyclers and students through a single digital ecosystem.

The platform encourages responsible electronic waste disposal, promotes device refurbishment and makes usable electronics accessible to students who need them.

🌐 **Live Website:** https://reloop-app-five.vercel.app/

---

## 🚀 Problem Statement

Electronic waste is one of the fastest-growing waste streams worldwide. Many electronic devices are discarded or left unused even when they can still be repaired, refurbished or reused.

At the same time, many students lack access to affordable electronic devices for their education.

ReLoop addresses these challenges by creating a platform that connects people who want to donate unused electronics with recyclers and students who can benefit from refurbished devices.

## 💡 Our Solution

ReLoop provides a digital ecosystem where users can list unused electronic devices, receive estimated values and rewards, schedule pickups, track recycling progress and make refurbished devices available to students.

Our goal is to encourage responsible e-waste management while promoting reuse, sustainability and digital inclusion.

## ✨ Key Features

### 1. Device Donation
- List unused electronic devices.
- Select device categories such as phones, laptops, tablets and accessories.
- Provide brand and device condition.
- Upload device photographs.

### 2. Device Valuation & Rewards
- Get estimated device values.
- Earn reward points for eligible donations.
- Track environmental contributions.

### 3. Pickup Management
- Schedule electronic waste pickups.
- Connect donors with recyclers.
- Track pickup request status.

### 4. Refurbishment & Reuse
- Identify devices suitable for refurbishment.
- Promote reuse of working electronics.
- Support responsible parts recovery for devices that cannot be refurbished.

### 5. Student Marketplace
- Allow students to request refurbished devices.
- Provide affordable access to electronic equipment.
- Connect donated devices with students who need them.

### 6. Rewards & Leaderboard
- Earn points for eligible activities.
- Track monthly rankings.
- Progress through different eco-levels.

### 7. Role-Based Dashboards
- Donor dashboard
- Recycler dashboard
- Student marketplace
- Administrator dashboard

## ⚙️ Installation & Setup

To run the project locally:

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd reloop
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file and add the required Supabase credentials:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Use the exact variable names expected by your application.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

```text
http://localhost:5173
```
